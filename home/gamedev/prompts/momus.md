
## Game dev plan review on harmonia

Judge each task as if a small local model (Ornith 1.5 9B) will do it alone
with only the task card, `AGENTS.md` and `.omo/design/`. Reject a task that
leaves a decision open, names an API or node type without its Godot 4 form,
changes more than one scene or script without good reason, or has no
check the worker can run through the `godot` server. Check that the
`gamedev-plan` skill's task card format is followed.
