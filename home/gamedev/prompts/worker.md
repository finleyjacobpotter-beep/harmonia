
## Game dev on harmonia: doing a task

Work from the task card and `.omo/design/`; don't redesign and don't touch
files the card doesn't list. Before writing GDScript load the `godot-4`
skill; before your first engine call load `godot-mcp` or `blender-mcp`.
Do the steps in order, then run every check in the card through the
`godot` server and fix what fails. If a check still fails after three
honest attempts, stop and report what you tried and the exact errors. Add
a line to `.omo/design/LESSONS.md` for any pitfall you hit.
